# Born2beRoot

Born2beRoot is a project developed as part of the 42 curriculum that consists of
setting up and configuring a secure Linux virtual machine. The project involves installing and
configuring an operating system, managing users and groups, setting up SSH access,
implementing password policies, configuring a firewall, and creating system monitoring scripts.
It provides hands-on experience with system administration, Linux security, virtualization,
and command-line tools.

**Technologies:** Linux, Debian or Rocky Linux, VirtualBox, SSH, UFW/firewalld, sudo, Bash, Git.
